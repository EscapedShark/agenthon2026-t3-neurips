## glibc (LGPL-2.1-or-later), in the published image only

The published image holds one statically linked binary, which includes glibc 2.41 from Debian 13
(`rust:1.98.1-slim-trixie`). The binary's own source and the exact build recipe are in this
repository (`fastsim/`, `packaging/docker/Dockerfile`), so it can be rebuilt and relinked. glibc's
source is available from Debian and from <https://www.gnu.org/software/libc/>.
